# ProyectoPAD Análisis Compras

En el área de compras de NovaPlas Hogar se requiere realizar periódicamente el análisis de diferentes productos para determinar cuáles deben ser adquiridos y en qué cantidad. Actualmente, esta decisión implica revisar información como inventario disponible, ventas mensuales, inventario mínimo, pedidos pendientes, tiempo de entrega, costos y presupuesto disponible. El análisis manual de estas variables puede dificultar la identificación oportuna de necesidades de abastecimiento y aumentar el riesgo de realizar compras innecesarias, generar sobrecostos o no disponer de productos suficientes.

Se propone desarrollar una solución algorítmica que permita procesar la información de los 1000 SKU, realizar los cálculos necesarios y aplicar reglas definidas por el área de compras. La solución deberá determinar si un producto requiere compra, calcular una cantidad sugerida respetando la unidad de empaque y verificar si el costo actual resulta conveniente frente al costo promedio. Finalmente, deberá considerar el presupuesto disponible y presentar los productos recomendados, el valor de cada compra, el total general y el total agrupado por marca.
